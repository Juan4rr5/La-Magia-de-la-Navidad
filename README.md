# 🎄 La Magia de la Navidad

¡Bienvenido a **La Magia de la Navidad**! ✨

Una pequeña experiencia navideña interactiva creada para disfrutar de la cuenta atrás hasta Navidad y compartir un poquito de la ilusión de estas fechas.

🎅 **¡La Navidad está cada vez más cerca!**

## ✨ Características

- ⏳ **Cuenta atrás navideña:** contador hasta el 25 de diciembre de 2026.
- ❄️ **Nieve animada:** disfruta de un ambiente invernal con nieve cayendo.
- 🎁 **Calendario de Adviento:** descubre la magia de la espera navideña.
- 🎄 **Árbol de Navidad interactivo:** decora tu propio árbol.
- 🎵 **Música navideña:** disfruta de música de fondo con controles de reproducción.
- 🔊 **Efectos de sonido:** pequeños detalles sonoros para mejorar la experiencia.
- 📱 **Diseño adaptable:** compatible con ordenadores, tablets y móviles.
- 🌟 **Sorpresa navideña:** al llegar el 25 de diciembre aparecerá el mensaje «¡FELIZ NAVIDAD!».

## 🛠️ Tecnologías utilizadas

Este proyecto está desarrollado utilizando:

- HTML5
- CSS3
- JavaScript

No necesita instalaciones adicionales para funcionar.

## 🎵 Música

La página incluye un reproductor de música navideña.

Por las restricciones de reproducción automática de los navegadores, tendrás que iniciar la música manualmente.

El archivo de audio debe encontrarse junto a `index.html` y tener el nombre `navidad.mp3`.
